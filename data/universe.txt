# Symbols the scheduled workflow fetches marks for.
#
# This list is a convenience, NOT the guarantee. Do not treat it as coverage.
#
# The owner's real book lives only in their phone's storage - it is read from a
# broker screenshot and never uploaded - so the workflow cannot ask what is
# held. No list can anticipate what someone will buy: an early version of this
# file held 168 names and a random sample of forty plausible holdings found
# thirty-eight of them missing.
#
# What this buys is a fresh common case with no key on the device. The
# guarantee comes from the app pricing exactly what is in `holdings`, which
# cannot fall behind because there is no list to maintain. A name held but
# absent here keeps whatever mark it had, and the Data sources screen says it
# was not refreshed.
#
# Sizing: Finnhub's free tier allows 60 calls a minute and the workflow runs
# every 30 minutes. At 537 names the sweep takes about ten minutes, so there is
# room to grow but not unlimited room: past roughly 1,400 a run would not finish
# before the next one started, and the schedule would need lengthening first.
